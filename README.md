# Kik

Peg på noget, og spørg. En lille guide i lommen, der bruger Claude til at fortælle, hvad du ser: bygninger, kunst, skilte, menukort, planter, produkter og maskiner.

**Åbn:** https://pbo-dot.github.io/kik/ (læg den på startskærmen fra Chrome-menuen)

- 📷 Tag et billede → kort svar → 🔊 læs op
- ✦ Fortæl mere (slår op på nettet) og spørg videre med stemmen
- Oversæt, pris og anmeldelser, "hvordan gør jeg?"
- Dagen samlet med rute og **Del → Dagbog**

Kræver din egen Claude-nøgle (under Mere). Alt gemmes kun på telefonen.
